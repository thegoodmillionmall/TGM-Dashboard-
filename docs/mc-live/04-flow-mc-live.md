# Flow การทำงาน MC Live

```mermaid
flowchart TD
  A["MC จบไลฟ์"] --> B["กรอกข้อมูลในแท็บ กรอกของฉัน"]
  B --> C{"เลือกประเภทกล้อง"}
  C -->|"มือถือ"| D["แนบ 3 รูป: หน้าไลฟ์ / ยอดขาย / จบไลฟ์"]
  C -->|"OBS"| E["แนบ 1 รูป: หน้าจอไลฟ์"]
  D --> F["ระบบคำนวณชั่วโมง ยอดขายต่อชั่วโมง และบันทึก"]
  E --> F
  F --> G["หัวหน้า MC ตรวจหลักฐาน"]
  G --> H{"ข้อมูลถูกต้องครบไหม"}
  H -->|"ไม่ครบ / ไม่ตรง"| I["ส่งกลับแก้ไข พร้อมเหตุผล"]
  I --> B
  H -->|"ถูกต้อง"| J["หัวหน้าเช็คแล้ว"]
  J --> K["ผู้บริหารตรวจภาพรวมรายเดือน"]
  K --> L{"ทุกรายการครบไหม"}
  L -->|"ยังไม่ครบ"| G
  L -->|"ครบ"| M["อนุมัติยอดจริงรายเดือน"]
  M --> N["ล็อกยอดเดือนนั้นเป็นยอดจริง"]
```

## สิทธิ์โดยบทบาท

| บทบาท | ทำอะไรได้ |
|---|---|
| MC | กรอกและแก้ไขรายการของตัวเองก่อนอนุมัติ |
| หัวหน้า MC | ตรวจหลักฐาน, ส่งกลับแก้ไข, แก้ไขรายการทีม |
| ผู้บริหาร | ดูภาพรวม, ตรวจรายคน, อนุมัติยอดจริงรายเดือน, เปิดเดือนกลับมาแก้ไข |

## เกณฑ์อนุมัติรายเดือน

ก่อนอนุมัติ ต้องผ่านครบทุกข้อ:

- รายการจบไลฟ์แล้ว
- เอกสารครบตามประเภทกล้อง
- หัวหน้า MC เช็คแล้ว
- ไม่มีรายการที่ถูกส่งกลับแก้ไขค้างอยู่
